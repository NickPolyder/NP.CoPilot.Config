# Retrospectives

Self-reflections after completing a feature, bug fix, or significant piece of
work in {{REPO_NAME}}: what went right, what went wrong, what to improve, and
what was learned.

- One file per retro (`{YYYY-MM-DD}-{topic}.md`).
- Capture durable lessons here; if a lesson is a permanent convention, also
  promote it to `.github/copilot-instructions.md` or an ADR.
