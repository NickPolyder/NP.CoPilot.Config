# Architecture Decision Records

Numbered records of significant architectural decisions for {{REPO_NAME}}.
Each ADR captures context, options, the decision, and its consequences so the
*why* survives long after the choice was made.

- Create new ADRs with the `architecture-decision-record` skill, or copy
  [`0000-template.md`](0000-template.md).
- Naming: `{NNNN}-{kebab-case-title}.md` (zero-padded 4-digit number).
- ADRs are immutable once accepted — to change one, write a new ADR that
  supersedes it and link them both ways.
