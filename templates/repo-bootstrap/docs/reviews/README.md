# Reviews

Code/design review findings for {{REPO_NAME}}, with tracked remediation. Use
this to capture multi-finding reviews (security audits, full-design reviews,
multi-model reviews) so the backlog of fixes isn't lost in chat history.

- One file per review (`{YYYY-MM-DD}-{scope}.md`).
- Give each finding a stable id (R1, R2, …) and track its remediation status in
  [`../TASKS.md`](../TASKS.md).

## Suggested finding format

```
### R1 — {short title}  ·  Severity: High | Medium | Low  ·  Status: open
**Where:** {file:line or component}
**Finding:** {what's wrong}
**Recommendation:** {what to do}
```
